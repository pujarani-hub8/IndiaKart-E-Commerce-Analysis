# IndiaKart E-commerce Data Analysis Project

## Project Overview
IndiaKart is an end-to-end e-commerce data analytics project focused on analyzing sales performance, customer behavior, product performance, and business operations. The main objective of this project is to transform raw data into meaningful insights that can help a business understand its performance and make data-driven decisions.

This project covers data cleaning, exploratory data analysis (EDA), key performance indicator (KPI) calculations, and dashboard development.

## Objectives
- Analyze overall sales and revenue performance.
- Understand customer purchasing behavior and customer value.
- Identify top-performing product categories.
- Analyze order cancellations, returns, and payment failures.
- Monitor inventory levels and identify stock-related issues.
- Calculate important business KPIs and generate actionable insights.

## Tools and Technologies
- **Python:** Data cleaning, analysis, and KPI calculations.
- **Jupyter Notebook:** Writing and executing Python code.
- **Pandas and NumPy:** Data manipulation and analysis.
- **Matplotlib and Seaborn:** Data visualization.
- **Power BI:** Interactive dashboard development.

## Project Workflow

### 1. Data Cleaning
Inspected the datasets to understand their structure and data quality. Checked missing values, duplicate records, data types, and potential outliers, and applied appropriate cleaning techniques.

### 2. Exploratory Data Analysis (EDA)
Explored sales, customer, product, and order data to identify patterns, trends, and relationships that could help explain business performance.

### 3. KPI Analysis
Calculated key business metrics, including:
- Gross Merchandise Value (GMV)
- Net Revenue
- Average Order Value (AOV)
- Order Cancellation Rate
- Return Rate
- Payment Failure Rate
- Customer Lifetime Value (CLV)

### 4. Dashboard Development
Designed a business dashboard to present important metrics and trends in an easy-to-understand visual format.

## Key Business Insights
- Electronics was the leading product category by revenue.
- The order cancellation rate was approximately 12%, indicating an opportunity to improve order fulfillment.
- The return rate highlighted a need to investigate product quality, sizing, and customer expectations.
- Payment failures and inventory availability were also examined to identify operational improvement opportunities.
- Year-over-year sales trends revealed changes in business performance over time.

This project helped develop practical skills in data cleaning, exploratory data analysis, business KPI calculations, data visualization, and communicating insights from data.

It demonstrates an end-to-end approach to solving business problems using data analytics.
